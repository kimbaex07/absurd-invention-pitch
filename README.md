This entry pitches the Sock Reunion Service, a dryer attachment that treats every vanished sock as a missing person. It files a formal report, issues a written apology, and delivers a replacement pair within 24 hours. The joke turns the tiny everyday annoyance of lost socks into full-blown bureaucracy — paperwork, apologies, and a replacement, all for one sock.

## Run it

```sh
python3 main.py
```
